# System Requirements

Before building the library, make sure your system meets the following requirements:

## Hardware Requirements
- **CPU:** 1 GHz processor or faster
  - multi-core processor recommended for faster compilation and running of the library
- **RAM:** 512 MB
- **Disk:** 20 MB free space

## Software Requirements
- **Operating System:** Linux or Windows
- **Compiler:** Must support **C++23**
  - *Linux:* GCC 13.0+ or Clang 16.0+
  - *Windows:* MSVC 2022 (v143 toolset) or newer
- **Build System:** CMake version 3.20 or newer
