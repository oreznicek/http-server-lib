# Documentation

Documentation is build using `doxygen`. You can view the [user documentation](./user_documentation.md) and the [programmer documentation](./programmer_documentation.md) even without doxygen, but the links (e.g., `http::Server`) will be broken, so it is highly recommended to use `doxygen`.

Run this in the `project` folder in order to build and view documentation.

```
doxygen
firefox html/index.html
```

(You can use browser of your choice of course and not only `firefox`).
