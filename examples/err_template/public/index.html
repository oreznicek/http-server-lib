HTTP Server Demo

This is a demonstration of how you can set up your custom error template pages in this C++ HTTP server library.

If you click the button below, it will attempt to navigate to the following undefined route:

/api/v1/trigger-random-error-page

Since the C++ Router does not have this path registered, and there is no file on that specific path in the public directory. It should safely catch the error, format the page and return a custom 404 response!
